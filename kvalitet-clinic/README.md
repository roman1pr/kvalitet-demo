# КвалитеТ — Demo Redesign

**This is a demo redesign** of the real dental clinic website [qualityclinic.ru](https://qualityclinic.ru/) (КвалитеТ, Moscow).

This project is a sales demonstration showing a modern, mobile-first approach to the clinic's web presence while preserving their brand identity and real content.

## About the Original

- **Clinic name:** КвалитеТ (from Latin *Qualitas* — точность и качество)
- **Location:** Москва, ул. Дубнинская, 13
- **Chief doctor:** Клепилин Егор Сергеевич
- **Website:** https://qualityclinic.ru/

## What This Demo Includes

- `index.html` — Homepage with hero, about section, services preview, doctors, reviews
- `uslugi.html` — Services & prices with real price tables
- `kontakty.html` — Contact information, directions, legal details
- `css/style.css` — Modern CSS with the clinic's brand colors

## Design Principles

### Preserved from the original brand:
- Color palette: cyan (#1c85bc), navy (#24466f), ink (#1e2428)
- Warm, approachable family clinic tone
- All factual content (doctors, prices, addresses, reviews)

### Modernized:
- Mobile-first responsive layout
- Clean typography (Cormorant Garamond + Source Sans 3)
- Lots of whitespace
- Single clear CTA
- No sliders, no stock photos, no lorem ipsum

## Technical Details

- Pure HTML + CSS (no frameworks)
- Tiny bit of JS for mobile menu and form handling
- Works as static files or on any static hosting
- Google Fonts for typography

## Usage

Open `index.html` in a browser, or serve with any static server:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```
